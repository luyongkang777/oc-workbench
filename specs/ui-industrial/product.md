# UI 工业级重构（ui-industrial）

## 目标

把工作台现有偏「温和灰 + 圆润」的界面，换成 Figma 设计稿 `92:2` 里的工业级专业风格：
冷哑光炭黑 / 哑光纸感浅色两套 token、正交几何线性图标（1.5px 描边）、
更紧的圆角与阴影、代码区统一等宽字体。**只改视觉，不改布局结构与交互逻辑。**

## 不做什么

- 不改三栏布局、不改控件高度、不改手机断点阈值（避免布局回归）
- 不改任何业务逻辑、API、状态管理
- 不改 `theme.ts` 的三态语义（跟随系统 / 暗 / 浅）
- 不引入第三方 UI 库、不引入外部字体文件（等宽字体只走本机字体栈）
- 不动 `specs/` 之外的项目文档

## 验收标准

1. `node node_modules/typescript/bin/tsc --noEmit` 无报错。
2. `npm test` 全绿（现有用例一条不减）。
3. 图标：`Icon.tsx` 全部 32 个图标路径重绘为正交几何线框，统一 1.5px 描边；
   `IconName` 联合类型一个不少，任何 `<Icon name=...>` 调用点都不需要改。
4. 暗色 token：底色 `#0D0E11`、面板 `#111216`、卡片 `#181A20`；文字四级
   `#ECEEF2 / #9DA2AF / #606573 / #3E424D`；主色换成冷青 `#38BDF8`。
5. 浅色 token：底色 `#F6F7F9`、面板纯白、墨黑正文 `#0F131A`、主色 `#0284C7`。
6. 圆角阶梯收紧为 2 / 3 / 4 / 6 px；阴影更内敛；新增 `--mono` 等宽字体栈。
7. CSS 结构检查（技能脚本 `css-check.mjs`）通过。
8. `npm run build` 通过（tsc + vite）。

## 约束

- 单文件改动 ≤ 300 行改动的部分；本次只落在 `Icon.tsx` 与 `base.css`
- 一次只做一条任务，做完验证再开下一条
- 颜色只改 token，不在业务 CSS 里散落硬编码
