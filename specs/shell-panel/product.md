# 产品文档 — 后台 Shell / 终端面板

## 目标

把 opencode CLI 里的 Shell 面板（Subagents / Shell / Terminals）搬到工作台网页里，用**按钮**触达，不依赖快捷键。

接入后用户能：

1. 看到当前目录下**正在跑**的后台命令（模型跑的、自己跑的），包括命令原文、状态、耗时。
2. 点开任一条看输出（后台命令读输出文件，持久终端读屏幕快照）。
3. 一键 kill（终止并移除）。
4. 看到持久终端（PTY）列表，同样能看快照、能 kill。

## 不做

- 不做快捷键绑定（用户明确不需要）。
- 不做「新建命令」入口（现有命令输入框已经能做）。
- 不做 Subagents tab（工作台已有独立的子智能体面板）。
- 不改服务端，只用现成 HTTP 接口。

## 验收标准

1. 底部终端条的头部出现「后台 Shell」按钮，带运行中数量；点开面板列出 `GET /api/shell` 里当前目录的命令。
2. 列表每条显示状态点、命令摘要、耗时；运行中的会随轮询更新状态。
3. 点击一条能展开输出；命令跑完后输出完整（含 stderr 合并）。
4. 点 kill 后服务端 `DELETE /api/shell/{id}` 生效，列表里消失。
5. 「会话终端」tab 列出**当前会话**的持久终端（`GET /api/experimental/session/{id}/terminal`），
   点开显示 snapshot 文本，移除后消失。顶层 `/api/pty` 是另一套 id 空间，不能用。
6. 后台请求失败时面板显示错误文案，不白屏。
7. 手机窄屏（390/320）不横向溢出。
8. `npm test` 全绿。

## 约束

- 单文件 ≤ 300 行，单函数 ≤ 50 行。
- 复用现有 `src/api/terminal.ts` 的请求封装（x-oc-token、withBase）。
- 面板默认收起，行为与现有终端一致。
