# 产品文档 — 终端停靠到编辑区（Cursor 式）

## 目标

把现在「全宽底部条」的终端，改成 Cursor 那样**停靠在文件查看区底部**的面板，并且：

1. **按钮开关**：顶栏一个终端按钮，点一下开/关；面板头部也有「×」关闭。
2. **自动调节高度**：拖上沿分隔条改高度，双击复位；高度记在 localStorage。
3. **顶部统计**：实时显示「运行中的智能体 N · Shell M」。
4. **状态以打勾为准**：命令只有退出码为 0（打勾 ✓）才算结束；非 0 显示 ✗，运行中显示转圈。

## 不做

- 不做多终端分屏（Cursor 有，但我们只有一个命令通道）。
- 不改现有三个 tab 的功能（后台 Shell / 命令 / 会话终端）。
- 不改手机端底部单列结构（手机上仍按原有移动布局处理）。

## 验收标准

1. 顶栏有终端按钮；点开后面板出现在编辑区底部，再点关闭。
2. 面板只占编辑区宽度，不伸到左右两栏下面。
3. 拖动面板上沿能改高度，最小 120px、最大不超过编辑区的 70%；双击复位到默认高度。
4. 刷新页面后开关状态与高度都保持。
5. 面板头部显示「N 智能体 · M Shell」，数字随轮询更新。
6. Shell 行状态：运行中转圈；退出码 0 显示 ✓；非 0 显示 ✗。
7. `npm test` 全绿，真机验收脚本全过。

## 约束

- 单文件 ≤ 300 行，单函数 ≤ 50 行。
- 复用现有 `beginResize` 的拖拽手感（含 zoom 换算）。
- 布局状态沿用 `useUiLayout` 的 localStorage 约定。
